Setup

1. MySQL
Run `backend/database.sql` in MySQL Workbench to create the database and tables.(Copy all stuff from database.sql and execute on MySql workbench)

2. Create `backend/.env`

```bash
MONGODB_URI=mongodb+srv://spencer:spencer@spencer.jw3h8fw.mongodb.net/leaderboardUsers?appName=Spencer
PORT=3000
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=spencer
DB_DATABASE=leaderboard_db
```

3. Backend

```bash
cd backend
npm install
npm run dev
```

4. Frontend

```bash
cd frontend
npm install
npm run dev
```
